A responsive recreation of the uploaded video using HTML, CSS and vanilla JavaScript.

## Included text effects
1. **Gradient Moving Text** — animated multicolor gradient flows across the text.
2. **Rotate In Text** — text rotates and scales into view.
3. **Blur Reveal** — blurred, spaced-out text sharpens into focus.
4. **Flicker Neon Text** — green neon sign flickers with a glowing text shadow.
5. **3D Flip Text** — text rotates in 3D on the X and Y axes.

## Features
- Dark navy gallery with orange outer border
- Individual preview and CSS snippet for each effect
- Copy CSS buttons
- Responsive desktop and mobile layout
- Reduced-motion preference support
- No external libraries or build tools

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000

## Files
- `index.html` — gallery structure and examples
- `style.css` — all five text effects and animations
- `script.js` — CSS snippet copy buttons

## Extraction note
The video shows portions of CSS and the rendered effects, not the full original source. This is a complete runnable reconstruction of the visible design and behavior, not a verbatim dump of unseen source code.
